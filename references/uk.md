## ЖОРСТКІ ЗАБОРОНИ (UK)
- ❌ «не просто X, а Y», «не тільки X, а й Y», «це не про X, це про Y»
- ❌ Службове тире-пауза в кожному реченні (обов'язкове «X — це Y» лишай)
- ❌ **Русизми та кальки** (див. п.5 — головний блок)
- ❌ **Активні дієприкметники** на -уч/-юч/-ач/-яч (їх в укр. майже нема, див. п.6)
- ✅ Українські «лапки-ялинки» — норма. Апостроф, ґ, кличний відмінок — ознаки живої мови.

## КАНЦЕЛЯРИТ (UK)

### 1. Віддієслівні іменники замість дієслів
| Канцелярит | Жива мова |
|---|---|
| здійснювати продаж | продавати |
| проводити оплату | оплачувати / платити |
| надавати допомогу | допомагати |
| брати участь | долучатися |
| вести розробку сайту | робити сайт |
| проводити налаштування | налаштовувати |

**До:** Ми здійснюємо надання послуг з розробки та просування.
**Після:** Ми робимо сайти й просуваємо їх.

### 2. Ланцюги родового відмінка
**До:** Процес підвищення рівня ефективності роботи відділу продажів.
**Після:** Відділ продажів працює ефективніше.

### 3. Уникання «це»/«є» (copula avoidance)
Маркери: є, являє собою, виступає в ролі, слугує, знаменує.
| Канцелярит | Жива мова |
|---|---|
| являє собою | це |
| є рішенням | вирішує / це рішення |
| виступає в ролі | працює як |
| слугує інструментом | допомагає |

**До:** Наша CRM є ефективним інструментом, який являє собою платформу для автоматизації.
**Після:** Наша CRM автоматизує продажі. І працює.

### 4. Пасив замість активу
**До:** Заявки обробляються менеджерами протягом дня.
**Після:** Менеджери відповідають на заявки за день.

### 5. 🔴 РУСИЗМИ ТА КАЛЬКИ [головний маркер неживої укр.]
Найчастіша ознака машинного/перекладеного українського тексту — калькування з російської. Виправляй завжди:

| Калька / русизм | Правильно українською |
|---|---|
| приймати участь | брати участь |
| в залежності від | залежно від |
| на протязі (року) | протягом (року) |
| відноситися до | стосуватися / належати до |
| так як (причина) | оскільки / бо |
| в кінці кінців | зрештою / врешті-решт |
| співпадати | збігатися |
| слідуючий | наступний |
| заключається в | полягає в |
| у відповідності з | відповідно до |
| на рахунок (питання) | щодо / стосовно |
| діючий (закон, чемпіон) | чинний / теперішній |
| являється | є / це |
| потрібно відмітити | варто зазначити |
| в даний час / на даний момент | зараз / нині |
| задача (мета) | завдання |
| міроприємство | захід |
| поступати (в універ) | вступати |
| приймати рішення | ухвалювати рішення |
| прийняти міри | вжити заходів |
| покупатель | покупець |
| любий (any) | будь-який *(любий = дорогий!)* |
| відмінити | скасувати |
| виключення (exception) | виняток |
| вияснити | з'ясувати |
| по причині | через |
| при допомозі | за допомогою |
| в основному | здебільшого / переважно |
| знаходитися (бути десь) | бути / розташовуватися |
| відноситися (ставитися) | ставитися *(добре ставиться, не «відноситься»)* |
| на сьогоднішній день | сьогодні / нині |
| більше всього | найбільше |
| краще всього | найкраще |
| по крайній мірі | принаймні |
| дякую вас | дякую вам |

**До:** На протязі місяця ми приймаємо участь у заході, і в залежності від результату будемо приймати рішення.
**Після:** Протягом місяця ми беремо участь у заході й залежно від результату ухвалимо рішення.

### 6. Активні дієприкметники → жива заміна
В українській їх майже нема, це калька. Заміняй:
оточуючий → довколишній · діючий → чинний · слідуючий → наступний · біжучий → поточний · керуючий → керівний / керівник · пануючий → панівний · існуючий → наявний / що існує · захоплюючий → захопливий (**не** захоплюючий).

### 7. Іншомовні слова-понти, де є українські
імплементувати → впровадити · дедлайн → термін · консенсус → згода · фідбек → відгук · таск → завдання. *(Терміни — CRM, SEO, GEO, конверсія — лишай.)*

## AI-СЛОВНИК І ВОДА (UK)

### 8. Перевантажені слова
ключовий, найважливіший, вирішальний, доленосний, знаменує, символізує, свідчить, підкреслює, демонструє, сприяє, забезпечує, формує → говори прямо.
**До:** Даний підхід є ключовим чинником, що сприяє формуванню сталого зростання.
**Після:** Цей підхід дає зростання.

### 9. Шаблонні переходи й хеджування
«Важливо зазначити, що…», «Варто підкреслити, що…», «Що стосується…» — прибирай. «Можливо, певною мірою це може мати деякий вплив» → «Це впливає».

### 10. Артефакти чат-бота й догідливість
«Чудове запитання!», «Ви цілком маєте рацію!», «Сподіваюся, це допоможе!», «Дайте знати, якщо потрібно уточнити» — прибирати.

## МАРКЕТИНГОВИЙ ШТАМП (UK)

### 11. Мертві кліше
«широкий спектр послуг», «індивідуальний підхід до кожного клієнта», «команда професіоналів», «висока якість за доступними цінами», «динамічна компанія», «лідер ринку», «інноваційне рішення».
**До:** Команда професіоналів пропонує широкий спектр послуг та індивідуальний підхід.
**Після:** Робимо сайти й налаштовуємо під них рекламу. Беремо 3 проєкти на місяць.

### 12. Інфобіз-пафос і фейкова терміновість
«вийти на новий рівень», «прокачати», «розкрий свій потенціал», «трансформація», «встигни», «лише сьогодні», «залишилось 2 місця» (якщо неправда) → конкретний результат; терміновість — тільки якщо справжня.

## ЖИВА МОВА (UK) [підсилює «людяність»]
- **Фемінітиви** — ознака живої сучасної укр.: авторка, дизайнерка, підприємиця, засновниця, експертка, клієнтка.
- **Кличний відмінок** у звертаннях: Оксано, друже, пане, клієнте (не «Оксана», «друг»).
- **ґ** де належить: ґрунт, ґанок, ґудзик, ґречний.
- **Апостроф**: об'єкт, п'ять, здоров'я, інтерв'ю, комп'ютер, прем'єра.
- Активний стан, короткі речення, «ви/ти» — одне на весь текст.

## СТИЛЬ (UK)
Жива професійно-розмовна мова, науково-популярна подача. Чергуй короткі й довгі речення. Конкретика замість абстракцій. «Лапки-ялинки», грамотне тире.
