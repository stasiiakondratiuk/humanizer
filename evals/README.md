# Evals — humanizer

Набор тест-кейсов, который измеряет главное: скилл **убирает AI-маркеры и слоп**, но **сохраняет смысл и факты**.

## Что внутри

- **`cases.jsonl`** — 27 кейсов (по 9 на RU / UK / EN). Каждая строка:
  ```json
  {
    "id": "ru-03",
    "lang": "ru",
    "tests": "маркетинговые клише",
    "input": "грязный текст на входе",
    "banned": ["строки, которых НЕ должно остаться в выводе"],
    "keep":   ["факты/числа, которые должны сохраниться"],
    "reference": "эталонная человеческая версия"
  }
  ```
- **`check.py`** — раннер на чистом stdlib (Python 3, без зависимостей).

## Как прогнать

**Проверить целостность набора и «золотые» эталоны:**
```bash
python check.py --validate    # структура cases.jsonl корректна
python check.py --selftest    # каждый reference сам проходит свои banned/keep
python check.py --list        # список всех кейсов
```

**Проверить конкретный вывод скилла.** Скорми `input` кейса скиллу `/humanizer`, результат передай раннеру:
```bash
python check.py --id ru-03 --text "Делаем сайты и настраиваем рекламу. Берём 3 проекта в месяц."
# или из файла:
python check.py --id en-02 --output out.txt
```
Раннер (без учёта регистра) проверит, что в выводе **не осталось ни одной** строки из `banned` и **сохранились все** факты из `keep`. Код возврата `0` — PASS, `1` — FAIL.

## Как читать результат

- **PASS** — вывод чист от маркеров этого кейса и сохранил факты. Это необходимое, но не достаточное условие: живость и голос `check.py` не измеряет — их оценивают глазами или LLM-судьёй по чек-листу из `SKILL.md`.
- **FAIL — still contains banned** — скилл пропустил маркер, паттерн надо усилить в соответствующем `references/*.md`.
- **FAIL — missing required facts** — переусердствовал, выкинул факт. Проверь блок «Калибровка» в `SKILL.md`.

## LLM-судья (опционально)

Для оценки того, что автоматом не проверить (ритм, голос, естественность), прогони пару `input → output` через модель с промптом: «Оцени по чек-листу из SKILL.md: 1) нет ли banned-маркеров, 2) сохранён ли смысл, 3) звучит ли как живой человек. Выстави PASS/FAIL и одну причину».

## Добавить свой кейс

Допиши строку в `cases.jsonl` (следи за валидным JSON, UTF-8), затем `python check.py --validate && python check.py --selftest`.
